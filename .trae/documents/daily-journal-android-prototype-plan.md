# 「每日记录」安卓 App 高保真原型 — 实施计划

## 概述

为"记录每一天，防止之后的日子忘记今天"构建一个**高保真 HTML 交互原型**：手机屏幕框架内运行的完整界面，浏览器打开即可体验。界面语言为**浅色轻盈 · 日系极简**（大道至简：颜色克制、靠留白与排版营造质感，同时保留强迫症式严格对齐），导航采用**中心径向菜单**（无底部 Tab 栏）。整体设计保持克制简单。

- 交付形态：纯静态 HTML/CSS/JS 原型（无构建依赖、离线可开）
- 技术栈：vanilla HTML + CSS + JS（单入口 `index.html` + 视图切换，无需路由）
- 产出目录：`/workspace/daily-journal/`（独立自包含项目文件夹）

## 现状分析

- 工作区 `/workspace` 下无任何现有安卓/日记类项目，为全新项目。
- 已有 `rocket-launch/` 等其他原型项目，互不干扰，新项目独立建目录。

## 设计契约（Design Contract）

### 设计令牌（浅色日系极简 · 8pt 严谨网格 · 大道至简）

颜色只做"底色 + 墨色 + 单一强调"，质感全部由留白、发丝线与排版承担——简单但不单调：

| 令牌 | 值 |
|---|---|
| 底色 | 主背景 `#FDFDFB`（微暖白）、卡片纯白 `#FFFFFF` |
| 墨色 | 文字墨阶 4 档：`#1A1A18` / `#6B6B66` / `#9C9C96` / `#D9D9D4`（信息层级靠深浅而非颜色） |
| 强调色 | 全站唯一强调色：柔和蓝 `#4E7CA1`（仅用于主操作、选中态、今日标记、进度指示，占比 <5%） |
| 语义色 | 心情不使用彩色图标，统一墨色描边线稿，仅选中项用强调蓝；语义红/绿仅限极小场景 `#C0574F` / `#5E8C61` |
| 分隔 | 发丝线 `1px solid #EDEDE9` 替代阴影，卡片靠边框+微弱底色差分层 |
| 间距 | 严格 8pt 网格：4 / 8 / 12 / 16 / 24 / 32 / 48，不允许任意值；页面左右页边距 20px，卡片内 padding 16px |
| 圆角 | 仅两档：卡片 10px、控件 8px |
| 字号 | 11 / 12 / 14 / 17 / 22 / 34（日系小标签 + 大标题对比）；正文行高 1.75、段落间距 12px，营造日式排版的呼吸感 |
| 数字 | `font-variant-numeric: tabular-nums`（日期/统计对齐强迫症核心） |
| 阴影 | 默认无阴影；仅径向菜单展开时使用一层极淡 `0 4px 16px rgba(26,26,24,.08)` 点出层次 |
| 字体 | 系统栈 `-apple-system, "HarmonyOS Sans SC", "PingFang SC", "Noto Sans SC", "Hiragino Sans GB", sans-serif`；标签类小字使用 `letter-spacing: 0.05em` 增加秩序感 |
| 图标 | Lucide 线性图标（1.5px 描边，与发丝线语言一致） |

### 布局骨架（App Shell）

- 手机框架：桌面浏览器中显示 390×844 手机外框居中（强迫症居中对称）；窄屏自动全屏。
- 顶栏（固定 56px）：左=当前视图标题（22px 墨色、清爽字重）、右=日期徽标（等宽数字）。顶栏与内容区之间用发丝线分隔。
- 内容区：单列滚动，所有卡片左右页边距统一 20px，卡片间距统一 12px。
- 底部：**无 Tab 栏**。仅底部中央一个 56px 圆形主按钮（径向菜单枢纽），展开后环形分布 4 个功能入口（今日 / 日历 / 统计 / 搜索），带当前视图高亮指示。展开时背景加半透明遮罩，再点收起。动画克制（150ms、单一缓动），遵循"设计更简单"的要求。

### 组件规范

- 卡片：白底、10px 圆角、发丝线边框 `#EDEDE9`、无阴影，内部 padding 16px
- 按钮：主按钮强调蓝实底白字、次按钮 1px 墨色描边幽灵样式；按压态统一透明度 0.7，无花哨特效
- 输入框：统一 40px 高、8px 圆角、发丝线边框、聚焦态 1.5px 强调蓝描框
- 心情选择：5 档横向等分选择器，线性图标统一墨色描边，选中项强调蓝 + 下方 4px 短横线指示
- 标签：12px、8px 圆角胶囊，`#F4F4F0` 底 + 墨色字，等距排列，选中态描强调蓝边
- 空状态：居中线性图标 + 一句话说明（日系克制文案，如"这一天，还没有留下记录"）
- 顶栏日期徽标：等宽数字 + 发丝线圆角框，如"2026.09.02 周三"

## 页面 / 视图清单（共 5 个视图，均在 index.html 内切换）

| 视图 | 职责 |
|---|---|
| 今日 | 撰写当日记录：日期头（星期/第几天）、心情 5 档、标签多选、多行文本、照片位（mock）、保存（stub） |
| 日历 | 月历网格（记录日打点、今日高亮描边），左右切换月份；点击任意日期 → 日详情 |
| 时间线 | 日历视图内子模式切换：纵向时间流列表，按月分组，倒序展示每天摘要 |
| 统计 | 记录总天数、连续记录天数、本月完成率、心情分布（CSS 条形）、标签频次排行 |
| 搜索 | 关键词输入 + 日期范围 + 标签筛选，结果列表点击进日详情 |
| 日详情（覆盖层） | 查看任意一天的完整记录：照片、心情、标签、正文；从日历/时间线/搜索均可进入 |

## Mock 数据

`mock.js` 内置约 90 天连续 mock 记录（中文正文、真实感日常内容），含：日期、心情档位、标签、正文、部分照片（使用 `https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=...&image_size=square_hd` 占位图，仅部分日期有图）、天气字段。提供 `api.js` 风格 stub（`getDay / getMonth / getStats / search`），所有交互只读 mock，不接真实后端。

## 实施步骤

1. 创建 `/workspace/daily-journal/` 目录结构：`index.html`、`styles.css`、`app.js`、`mock.js`、`assets/`
2. 写入设计令牌与 App Shell（顶栏 + 手机框架 + 径向菜单）至 `styles.css` / `index.html`
3. `mock.js`：90 天 mock 数据 + stub API
4. `app.js`：径向菜单展开/收起与视图路由、日历渲染与月份切换、时间线列表、统计计算（纯 CSS/SVG 图表，不引库）、搜索过滤、日详情覆盖层
5. 静态走查（③.5）：所有交互绑定齐全、无重复 id、无死链、径向菜单四入口视图切换正确、8pt 网格抽查（间距仅允许令牌值）
6. 交付 `computer://` 链接

## 假设与决策

- 视觉风格用户最终确认为**浅色轻盈 · 日系极简**（第一轮曾选商务蓝灰，后改为日系浅色并强调"大道至简的简单、不是单调"）：全站唯一强调色柔和蓝，层级靠墨色深浅与留白，不依赖多彩装饰；径向菜单只保留 4 个入口。
- 照片使用 trae-api 文生图 URL（符合 Web 图片规范）；如个别图质量不佳，用 GenerateImage 生成后存入 `assets/` 替换。
- 原型数据不落 localStorage（保持 mock 只读、刷新可复现）；"保存"为 stub 交互反馈（轻提示"已记录"）。
- 单入口无路由（纯前端视图切换），符合纯静态交付。

## 验证方式

- 静态代码走查：视图切换逻辑、径向菜单状态、日历月份边界（含 2026-09 当月）、搜索空结果空状态、统计数字与 mock 数据一致性
- 间距/圆角/颜色全部走 CSS 变量，抽查无魔法数
- 交付后由用户在浏览器中体验，如需迭代（改文案、调布局）按 iterate 流程局部修改
